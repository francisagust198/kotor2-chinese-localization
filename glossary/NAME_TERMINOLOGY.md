# 人名全称与拆分称呼

校对时按原文实际使用的称呼处理，不能只匹配全称，也不能把姓名的一部分自动扩成全称。

| 全称 | 单独的名 | 单独的姓 |
| --- | --- | --- |
| Chodo Habat → 乔多·哈巴特 | Chodo → 乔多 | Habat → 哈巴特 |
| Loppak Slusk → 洛帕克·斯拉斯克 | Loppak → 洛帕克 | Slusk → 斯拉斯克 |
| Jana Lorso → 贾娜·洛尔索 | Jana → 贾娜 | Lorso → 洛尔索 |
| Atton Rand → 亚顿·兰德 | Atton → 亚顿 | Rand → 兰德 |
| Tienn Tubb → 蒂恩·图布 | Tienn → 蒂恩 | Tubb → 图布 |
| Dhagon Ghent → 达贡·根特 | Dhagon → 达贡 | Ghent → 根特 |
| Arren Kae → 艾伦·卡娅 | Arren → 艾伦 | Kae → 卡娅 |
| Ulic Qel-Droma → 乌利克·凯尔-德罗马 | Ulic → 乌利克 | Qel-Droma → 凯尔-德罗马 |

`terms.jsonl` 的 `name_forms` 明确列出全称、名、姓或去除称号后的称呼。称号如 Master、Darth 与人物姓名分别核对；“侍女”“门徒”等身份称呼可按语境保留，不能一律换成未揭示的本名。

`person-name-rules.json` 保存本轮逐项核对的旧译变体和原文限制条件。`tools/name_terminology.py` 只在哈希验证后的英文原文提及相关姓名时修订指定中文变体，保留变量与制作备注；已弃用的旧“部分姓名→完整姓名”自动规则禁用。

例如，“罗帕克”只能改为“洛帕克”，不能在原有“·斯拉克斯”前再次补入姓氏。已经形成的“洛帕克·斯拉斯克·斯拉克斯”应修为“洛帕克·斯拉斯克”。同一句分别两次提及同一人物时，两次姓名都保留。

不要把 `Visas` 的普通复数“签证”、`Mission` 的普通名词“任务”、脚本变量 `203TEL_Habat` 或制作备注当作玩家可见姓名。`Jekk Jekk Tarr` 的重复是专名本身，不能按重复人名删去。

本轮是姓名一致性专项核查，不代表全部对白逐句完成语义终审。英文原文应从合法本机游戏与前置 MOD 恢复，不随仓库发布。
