# 为其他 MOD 制作汉化补丁

可以复用本项目的 TLK/GFF 读写、字形编码、字体和存档处理方案，也可以独立发布补丁。建议以目标 MOD 的明确版本为基线。

1. 读取目标 MOD 实际使用的 TLK 和局部文本，而不是仅按同编号沿用本项目译文。
2. 为每条英文原文保存 SHA-256，记录容器、资源类型、字段和语言/性别；相同英文有不同语境时分别校对。
3. 决定如何合并 TLK。两个覆盖 `dialog.tlk` 的 MOD 不会自动合并；新增条目及 StrRef 要在最终组合中一致。
4. 对 GFF 局部字符串按字段和来源摘要替换，保留未翻译字段、脚本、语音、性别和资源标识。
5. 使用当前字体映射编码中文，保留 `<CUSTOM0>`、`%d` 等运行时变量。新汉字需增加映射并验证所有相关字体。
6. 若覆盖同一个模块或 GUI，要把双方改动合并，不能靠加载顺序让其中一个 MOD 静默失效。
7. 写清前置版本、加载顺序、冲突范围、是否需要新存档或转换副本，再进行实机测试。

Steam 工坊不会执行存档工具，也不会自动把 DLL 复制到游戏根目录。补丁若需要原生组件，应明确说明安装方式。

取得目标 MOD 的再发布许可并保留作者致谢。仓库源码的 MIT 授权不授予其他 MOD、字体或原译文的所有权。
